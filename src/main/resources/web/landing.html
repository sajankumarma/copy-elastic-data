How each tool works

Copy data from tenant

  1. Configure source & target connections via Update Config.
  2. Pick an ES index, data object types, or specific document IDs.
  3. The tool searches source ES and pushes each document into target ES.

Bulk object create

  1. Configure the platform connection (manage URL, tenant, auth) via Update Config.
  2. Paste any platform /get response — entities, models, generic objects, requests, configs…
  3. The tool calls /create on the selected service once per object.
